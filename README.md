規格外の花の集荷を仲介するプロトタイプアプリ(単一HTMLファイル)。

構成:
フレームワーク・ビルド不要。index.html を開くだけで動作する静的ページ。
画面は3タブ切り替え式:
加工会社として発注する(companyView)
農家として納品する(farmerView)
集荷ダッシュボード(brokerView)

データ保存:
サーバーなし。すべて localStorage に保存(キー: hd_orders_v1, hd_deliveries_v1)。
端末・ブラウザをまたいだ共有はされない(同一ブラウザ内でのみ永続)。
写真からの色判定(簡易AI的処理)
extractColor()(script内)で実装。
写真を48×48pxのcanvasに縮小 → 全ピクセルのRGB平均を算出 → HSLに変換 → 色系統(紅・山吹・緑・藍・紫・淡色)に分類。
あくまで平均色による簡易判定であり、品種判定・等級判定は未実装(今後の課題)。
